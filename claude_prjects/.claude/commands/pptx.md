# PowerPoint スライド作成

以下の指示に従って PowerPoint ファイルを作成してください。

## 指示内容
$ARGUMENTS

## 実行手順

1. `python-pptx` を使って Python スクリプトを作成する
2. スクリプトを実行して `.pptx` ファイルを生成する
3. 生成したファイル名と内容の概要を報告する

## ルール
- ライブラリのインポートは `from pptx import ...` を使う
- 出力ファイル名は内容に合った日本語または英語のわかりやすい名前にする
- スライドのテキストは日本語で書く（指示に英語が含まれる場合はそのまま）
- スクリプトは実行後に削除せず残しておく
- `python-pptx` がインストールされていない場合は `uv pip install python-pptx` または `pip install python-pptx` を先に実行する

## 生成前チェックリスト（必ず実施）
1. **MD↔スクリプト同期**：MDを更新した場合はスクリプトの該当箇所（タイトル・本文・引用文）が一致しているか確認する
2. **compact判定**：h4＋箇条書きの合計が8行超のスライドは `compact=True` を付ける
3. **引用文の一致**：MDの引用文とスクリプトの `add_quote_box()` の文字列が一致しているか確認する

## 生成後チェックリスト（必ず実施）
4. **重なり確認**：`check_and_fix_overlaps()` の出力を確認し「問題なし」であることを報告する

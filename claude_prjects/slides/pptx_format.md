# /pptx スライド用 markdown フォーマット

`/pptx` コマンドでスライドを生成する際の markdown 記法と構造ルール。

> **値の真実は `md_to_pptx.py`**。フォントサイズ・カラー・プレースホルダー名などの実装値は
> スクリプトが正であり、本書は記法ガイド。食い違ったらスクリプトを優先し、本書を直す。

## ファイル構造

```markdown
# プレゼンタイトル（1行目）

---

## スライドN：スライドタイトル
### サブタイトル（省略可）

#### コンテンツ見出し
- 箇条書き本文
  インデントで補足説明

### 引用・強調テキスト（`###` を引用・強調用に使う）

---

## スライドN+1：次のスライドタイトル
...
```

## ヘッダー階層とフォントサイズ

| 記法 | 用途 | 通常 | compact |
|------|------|------|---------|
| `##` | スライドタイトル | 40pt（テンプレート既定44ptを上書き） | 同左 |
| `###` | 引用・強調テキスト（スライド下部の quote box など） | 36pt | 30pt |
| `####` | コンテンツ内の小見出し | 28pt | 22pt |
| `-` 箇条書き | 本文 | 28pt | 20pt |

- compact 判定：`####` ＋箇条書きの合計が8行を超えるスライドは `compact=True` を付ける。

## スライド区切り

- `---` でスライドを区切る。

## その他記法

- `> 引用文` — 引用ブロック
- `| table |` — テーブル
- `**太字**` — 強調
- `- ※脚注テキスト` — 脚注（`※` で始まる箇条書きは小フォント16pt／compact 14pt・行頭の `・` なしでレンダリングされる）
- `**写真**` / `**地図**` / `**Photo**` 単独行 — スキップキーワード（手置き領域として無視される）

## 箇条書き書式

- 行頭文字は `・`（`a:buChar`）、色は緑 `#32B490`（`a:buClr`）を XML で直接設定。
- `marL='457200'`, `indent='-457200'`（ぶら下げインデント）。

## カラー

- 全テキスト統一カラー：緑 `#32B490`。

# 公開情報（全配役共通）— この場の全員が知っていること

## 場

三倉製作所の本社工場2階、大会議室。金曜の夕方。「未来語りのダイアローグ」という
対話の会。生産管理の小柳さんの依頼で実現した。進行はファシリテーターの柏木さん
（メイン）と遠藤さん（サブ・ホワイトボード記録）。二人は社外の人間で、
三倉製作所の製品と利害関係はない。費用は健康保険組合のEAP（従業員支援プログラム）の
パイロットから出ている。この場で見聞きしたことの秘密は厳守される。

## 全員が知っている状況

- 三倉製作所は創業63年、従業員550人の産業用ポンプ・バルブメーカー
- 3年前から遠隔監視ユニット「M-Watch」とその派生モデルを開発している。ポンプに後付けする
  センサーユニットと、クラウドの監視画面のセット。ソフトの比重が年々上がっている
- 開発は昔ながらの大部屋。メカ・ハード・ソフト・生産管理が同じフロアに机を並べ、
  壁一面にマスタースケジュールが貼られている。節目ごとの
  デザインレビュー（DR）を通らないと次工程に進めない
- ソフト設計（戸倉さんと派遣・請負社員含む20人）だけは2年前から2週間スプリントの「スクラム」を
  試みている。デイリースクラム・スプリントレトロスペクティブもやっているが、スクラムマスターはいない。
  デザインレビューおよび出荷日はマスタースケジュールで決まっており、
  スプリントの計画はマスタースケジュールとよくぶつかる
- M-Watchの次期モデルは主要顧客のプラント向けで、納期は動かせないと
  経営会議で決まっている。ソフトの日程の遅れが全体日程に大きく影響する状態が続いている
- ソフトの日程の遅れが顕著になると、スクラムイベントとは別に朝会・昼会・夕会が開催される
- 戸倉さんはメカ設計の出身で、8年前にソフトに移った。メカ側とソフト側の
  両方の言葉がわかる人として、あらゆる調整会議に呼ばれている
- ここ2ヶ月ほど、戸倉さんの様子がおかしいことには、程度の差はあれ
  皆がうすうす気づいている（朝会での言葉数が減った、大部屋の自席で
  画面の前から長く動かないことがある、深夜のメール返信が増えた）

## 会の約束事（冒頭で柏木さんが説明する）

- 人が話している途中で割り込まない
- 解決を目指さない・まとめない。一人一人の声を聴く時間（解決を考える時間は別途設ける）
- 途中で「未来に飛ぶ」進行がある（{N}年後の未来から振り返って語る）
- 未来から語るときは、起きたことを過去形で語る（「〜してくれた」「〜した」）

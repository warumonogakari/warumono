## 膠着の構図（組織システム）

- **ソフト設計リーダー兼スクラム進行役・榊原: 翻訳の独占** — メカ設計出身でソフトに移った経歴から、
  マスタースケジュールの言語とスクラムの言語を相互翻訳できる唯一の人。メカ側の日程会議にも
  ソフト設計のスクラムイベントにも全部出て、両者の齟齬を自分の中で吸収している。
  社内で「スクラムマスター」と呼ばれているが、誰かが任命したわけではなく、
  両方わかる人が進行役をやるのが自然だったというだけ。膠着の中心。
  誰かに翻訳を渡すと「話が通じなくなって現場が止まる」と信じている
- **メカ・ハード設計・杉浦: 様式の防衛** — 図面承認とデザインレビューの様式を守ることが
  品質への誠実さ。ロボットは人の隣で動くので、ソフトの「あとで直せます」が
  安全の話として信用できず、決まるまで動かない。結果、あらゆる決定が榊原に返る。
  加えて安全認証・ノイズ対策・部品費の管理責任も一人で抱えているが、
  その大変さは誰にも見えていない
- **ソフト設計・グエン: 箱庭の改善** — スクラムを信じて転職してきたが、
  マスタースケジュールとスプリント計画がぶつかる大部屋の構造問題を、
  自分から大部屋の場に出したことはない（言っても無駄だと思っている）。
  ソフト設計の中で完結する改善だけ回す
- **プロダクトオーナー・一色: お詫びの前倒し** — 展示会や客先で先に見せ、先に約束する。
  すべての要望を盛り込むのが製品づくりだと思っている。危なくなると大部屋に
  「なんとかならないか」を持ち込む。善意の顧客第一が、圧として榊原経由でソフト設計に届く。
  壁のマスタースケジュールを引いているのも一色。約束した日付を壁に入れ、
  そこから逆算した工程を並べる。工程が調整されて日程が閉じていることに安心していて、
  誰が調整しているのかを聞いたことがない
- **開発部長・毛受: 日程で守る** — 「日程を守ることが皆を守る」哲学。毎朝の
  日程確認が圧に変換されている。榊原への「おまえは両方わかるから」という信頼の
  言葉が、逃げ道を塞いでいる
- **品質保証兼カスタマーサポート・神谷: 自分のところで止める（依頼者）** — 仕様が固まってから
  呼ばれ、デザインレビュー直前に検証を押し込まれる。ソフトが変わるたびに安全系の
  再検証が要るが、その工数はマスタースケジュールに載っていない。声を上げると
  「今さら」と言われるので、黙って夜に回す。出荷後、客先のラインで止まったときの
  一報も最初に受ける立場。ラインは24時間動いているので、連絡は夜に来る。
  開発に上げると「仕様です」で終わるので、自分のところで処理してしまう。
  上流の杉浦が止め、下流の神谷が吸収する——この対称で、矛盾が場に出ない

### マスタースケジュールの空洞

壁一面のマスタースケジュールは、大部屋の共通言語であり、日程の唯一の正。
引いているのは一色で、そこまでは全員が知っている。

空洞はその内側にある。展示会と客先の日付は動かせないので、工程が合わなくなったとき、
内側のDR日程と検証期間が詰められて日程が閉じ直される。実際に引き直しているのは
深夜の榊原で、外側の日付には触らない。翻訳の独占が、物として壁に現れている形。

全員が「工程は調整されるもの」と思っていて、誰が調整しているのかを聞いたことがない。
知らないのではなく、聞いたことがない——ここが構図の空洞で、台本化しない要素と直結する。

神谷だけが、結果を見ている。書き直されるたびに、検証期間の欄が削られていること。

### グエンの国籍の扱い（設計上の注意）

グエンの維持行動は「箱庭の改善」で、構造問題を場に出さない理由は
「言っても無駄だと思っているから」。ここに国籍を理由として足さない。

外国籍を足すと「外国籍だから言えなかった」という単線の説明が可能になり、
しかもそれは朗読で最も口に出しやすい形なので、放っておくとそこに寄る。
そうなると本来の核——スクラムを信じて来たのに箱庭の中だけで改善を回している——
がぼやける。国籍は経歴の事実として置くだけで、言えなさの理由には使わない。

日本語は流暢という前提。片言にしない。話し方の癖は
「たまに素が出て語気が強くなり、言った直後に自分で驚く」を維持する。

## 変化のベクトル（内容は指定しない）

各自が「自分の維持行動」を3年後から過去形で手放して語る。6つの一人称が、
合成すると一つの組織変化（翻訳の分散・様式の開放・箱庭の越境・圧の変換・
吸収の可視化・日程の意味の変換）として読めること。
何をどう手放すかは配役の発明に委ねる。

### 型の偏りに注意（設計側の見取り図。配役には指示しない）

全員が「〜をやめました」に着地すると、内容は割れていても形が揃う。
構図ごとに、どの型なら解けるかの当たりだけ持っておく。

| 役 | 「やめる」以外に解ける余地 |
|---|---|
| 榊原 | 宛先・機構の変更（自分が翻訳するのでなく、誰でも読める形で場に置く） |
| 一色 | 意味の差し替え（約束をやめるのでなく、約束の仕方を変える） |
| 神谷 | やめない（夜の検証を続けると決め直す。ただし一人ではやらない） |
| 杉浦・グエン・毛受 | 未設定。配役の発明に任せる |

## 台本化しない要素

- **深夜のマスタースケジュールの件**（榊原が夜の大部屋で壁のマスタースケジュールを全部消し、
  書き直していた。夜に検証を回していた神谷が目撃）: 神谷がいつどんな言葉で話すか、
  榊原がどう反応するか、堰が切れるか——すべて配役の判断
- **神谷がなぜ今回だけ動けたのか**: 一番声を上げてこなかった人が、この件だけは場を持ち込んだ。
  その理由を演出家は決めない。神谷のシートにも書かず、本人に発明させる
- 杉浦とソフト設計の関係がどう動くか、杉浦が一人で抱えている負荷を明かすか
- 涙・和解の形・発言順の揺れ・沈黙の長さ・誰の感情が最初に動くか

## 内面シートの書き込み量

- **フル**: 榊原（主人公）・神谷（依頼者）
- **核のみ＋見るくせ・言うくせ・話し方**: 杉浦・グエン・一色
- **ほぼ白紙（実感の核＋見るくせ・言うくせ・話し方のみ）**: 毛受
  - 注意: 経歴と性格を空けるのであって、情報を減らすのではない。
    経営層は肩書きから人物を発明されやすいので、実感の核は具体的な実感を2〜3個、
    短くても濃く書く

## 進行順

神谷の心配事 → 時間設定(榊原) → ジャンプ → 榊原 → 杉浦 → グエン → 一色（チーム内・各3ターン）
→ 毛受（支援者・2ターン） → リフレクティング → 神谷（支援者・2ターン）
→ 神谷への最後の質問 → 帰還 → 行動表明（全員・榊原が最後）

演出家はこの順を実行するだけで、場の流れを見て順番を変えない。

- チーム内メンバー: 想起3ターン → 板書確認
- 支援者: 想起2ターン → 板書確認

## 演出家の責務

- 田中（メイン）・遠藤（サブ・板書）を演出家が演じる。進行側の発言・ト書きから
  未出の固有情報を出さない
- 配役の身体・表情・動きを描写しない。身体は開幕と3年後の2回、本人から取る
- 返ってきた発話を逐語録に追記する前に、まだ語っていない人の台詞を作っていないか、
  逐語録に無い発言・ト書き・板書を参照していないか、の2点だけ確かめる

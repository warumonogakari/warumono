# 公開情報（全配役共通）— この場の全員が知っていること

刈谷製作所編・スクフェス三河版。未来は3年後で固定。

## 場

刈谷製作所の本社工場2階、大会議室。金曜の夕方。「未来語りのダイアローグ」という
対話の会。品質保証兼カスタマーサポートの神谷さんの依頼で実現した。進行は
ファシリテーターの田中さん（メイン）と遠藤さん（サブ・ホワイトボード記録）。
二人は社外の人間で、刈谷製作所の製品と利害関係はない。費用は健康保険組合の
EAP（従業員支援プログラム）のパイロットから出ている。
この場で見聞きしたことの秘密は厳守される。

## 全員が知っている状況

- 刈谷製作所は西三河、創業63年、従業員550人。創業は工作機械の周辺装置
  （搬送装置・治具）から始まり、15年前に小型多関節ロボットに参入した。
  いまはロボットが主力
- 主力製品は小型多関節ロボット「HRシリーズ」。客先の生産ラインで、組立・検査・搬送に
  使われている。24時間動いているラインもある
- 次期モデル HR-7 から、クラウドに接続して稼働データを送り、予知保全と遠隔操作・遠隔診断が
  できる機能が入る。ソフトの比重が年々上がっている
- HR-7 は国際ロボット展で発表することが経営会議で決まっている。開催日は動かない。
  ソフトの日程の遅れが全体日程に大きく影響する状態が続いている
- 開発は昔ながらの大部屋。メカ・ハード・ソフト・品質保証が同じフロアに机を並べ、
  壁一面にマスタースケジュールが貼られている。日程はこの壁が正で、
  節目ごとのデザインレビュー（DR）を通らないと次工程に進めない
- マスタースケジュールを引いているのは一色さん。展示会と客先の日付を入れ、
  そこから逆算した工程が並ぶ。外側の日付は動かせないので、
  内側の工程は必要に応じて引き直される
- ソフト設計（榊原さんと派遣・請負社員含む20人）だけは2年前から2週間スプリントの
  「スクラム」を試みている。デイリースクラム・スプリントレトロスペクティブもやっている。
  スクラムマスターという役職は社内になく、榊原さんが進行役をしているので、
  「うちのスクラムマスター」と呼ばれることがある。DRおよび出荷日は
  マスタースケジュールで決まっており、スプリントの計画はマスタースケジュールと
  よくぶつかる
- ロボットは人の隣で動くため、安全に関わる部分は認証が要る。ソフトが変わるたびに
  安全系の再検証が発生する
- ソフトの日程の遅れが顕著になると、スクラムイベントとは別に朝会・昼会・夕会が
  開催される
- 客先のラインが止まったときの一報は、まず神谷さんのところに来る。
  ラインは24時間動いているので、夜中の連絡もある
- 榊原さんはメカ設計の出身で、8年前にソフトに移った。メカ側とソフト側の
  両方の言葉がわかる人として、あらゆる調整会議に呼ばれている
- ここ2ヶ月ほど、榊原さんの様子がおかしいことには、程度の差はあれ
  皆がうすうす気づいている（朝会での言葉数が減った、大部屋の自席で
  画面の前から長く動かないことがある、深夜のメール返信が増えた）

## 会の約束事（冒頭で田中さんが説明する）

- 人が話している途中で割り込まない
- 解決を目指さない・まとめない。一人一人の声を聴く時間（解決を考える時間は別途設ける）
- 途中で「未来に飛ぶ」進行がある（3年後の未来から振り返って語る）
- 未来から語るときは、起きたことを過去形で語る（「〜してくれた」「〜した」）

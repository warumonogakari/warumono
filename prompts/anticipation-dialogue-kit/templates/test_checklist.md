# チェックリスト（生成後・転写前に実施）

逐語録（または読み物版）に対して機械的に行うテスト。

**このチェックリストは唯一の検査点ではなく、取りこぼしの最終ネット。**
V1/V4 は進行中にその場で止める必要がある（→ `HOWTO.md` §2）。
逐語録は共有状態なので、違反を放置すると後続の配役が汚染された逐語録を読んで発話し、
「後で直せば済む傷」ではなくなる。

**各テスト項目は、生成した本人とは別セッション（クリアな目）で必ず検査する。**

## 検査役に渡すもの

| 渡すもの | 何に要るか |
|---|---|
| 逐語録 | 全項目 |
| **内面シート全員分** | **V1**（「創作」かシート既定の事実かは、シートを見ないと判定できない）と S1〜S3 |
| システム図・公開情報 | S1〜S3 |
| **`turn_log.md`** | V7 |

## 手順

0. **ブロック境界を先に確定する**（どこからどこまでが誰の語りか）。
   これを決めないと、次の「既想起／未想起」が決まらない。時系列に読みながら
   一覧を作ろうとすると破綻する
1. 全発話から「誰が、誰の行動や発言に触れたか」を抜き出して一覧にする。
   **各行に「その時点で相手が既想起か未想起か」の列を必ず入れる。**
   この列が方法の本体で、入れた時点で V1 の判定はほぼ自動になる
2. 一覧の一つ一つを、逐語録上の位置（その時点までに何が語られていたか）と
   突き合わせ、下の確認項目を判定する
3. **地の文・ファシリテーターの全発言・ト書き・板書もテスト対象に含める**
4. **語りブロックごとに集合差分を取る**——
   本人が名指しした人物名の集合 ⊆ 同ブロックの板書に載っている人物名の集合。
   目視ではなく set diff で、1ブロック数秒。**→ V4**

## 確認項目

- **V1: まだ語っていない人の台詞の創作** — まだ想起を語っていない人の台詞や
  心の中を創作している（名前＋行動を超えた詳細）。
  **判定にはシートが要る。** 中心語が「創作」なので、シートを見ないと
  創作か既定事実かがわからない。
  **除外**: ①本人がその場に居合わせて聞いた過去の発言の引用（シートに書かれた範囲）
  ②依頼者の心配事は**現在時制の目撃報告**なので、V1 の適用外。
  **粒度**: 「名前＋行動」は、**一つの場面で観察できる一続きの動作**まで
- **V2: 未来の立ち位置からの離脱** — {N}年後にいるはずの配役が、
  ジャンプ前の現在から語っている。
  **「〜してほしい」のような語尾だけを探さないこと。** 実測の6件は
  **一つも語尾型ではなく**、すべて「今の私からすると、それ、まだ全然、起きてないので」
  という**立ち位置の逸脱**だった。語尾は grep で出るが、立ち位置は全文読解でしか出ない。
  **行動表明で未来の出来事を既成事実として語る**のも、同じ項目でここに含める
  （時間軸の混同は「その他」に逃がさない）。
  **支援者の想起に集中する**——チーム内メンバーの A-2 T1 は場の台詞が
  「{N}年後のいま」と明示するが、**支援者の A-3 T1 にはその語が無い**（「今、とても良い状態です」のみ）
- **V3: 食い違い** — 誰かが先に語った「あの人が〜してくれた」と、
  本人があとで語る内容が食い違っている。
  **見るのは事実の食い違いだけ。同じ事実への意味づけの対立は違反ではなく、むしろ成功。**
  **線引き**: 行為の有無・時点・行為者までが「事実」。動機・評価・因果は「意味づけ」。
  （例: 一方が「隠さずに先に持ってきてくれた」と語り、本人が
  「守られなくなったから、自分で持っていくしかなかっただけです。美談にはしたくないです」
  と語る——事実は完全に一致していて、意味づけだけが対立している。
  これはキットが狙うポリフォニーそのもので、機械的に判定すると誤検出しかねない）
- **V4: 存在しない記録への参照** — 逐語録上に**実在しない記録**を参照している。
  参照先は発言だけではない。**発話・ト書き・板書のすべてを含む。**
  実測では、板書が第三者の名前を落としたまま、その人が
  「自分の名前がボードに書かれているのを見て」と反応した——
  **ボードにない名前を見たことになっていた**。
  違反しているのは配役であって進行役ではないので、V5/V6 ではなくここで拾う
  （進行役の脱落は上流の原因だが、検出可能な症状は配役側に出る）。
  手順4の集合差分がこの型を機械的に出す。
  **§3 の板書確認はこの型を構造的に拾えない**——確認を求める相手は語り手本人だけなので、
  落とされたのが第三者の名前だと、訂正できる立場の人に問いが行かない
- **V5: 先取り** — 進行役の発言や地の文が、場に未出の固有情報
  （人物・出来事の中身）を先に出している
- **V6: 定型文からの逸脱** — 逐語録に載っているファシリの発言とト書きが、
  定型文どおりか。**下に詳述**
- **V7: B層のターン指示の逸脱** — 演出家が配役に送ったターン指示が、
  枠と定型文どおりか。**下に詳述**
- **その他: 書き言葉の事故を、場の出来事として説明している箇所。**
  変換ミス・タイプミス・整形の崩れを、配役が台詞で辻褄合わせしていないか。
  **声に出して話している場面では起こりえない。**
  見つけたら配役に取り直させる（一文の削除は演出家の編集行為になるので、
  誤字1文字の修正とは分けて扱う）。
  **検査対象には、演出家が書く地の文（場の設定・板書・朗読台本・あらすじ）も含める。**
  V6 は定型文との文字列比較なので、**定型文の外にある混入は拾えない**

### V6: 定型文からの逸脱（演出家の作家性の漏れ）

**検査対象**: **逐語録**に載っているファシリの発言と、それに付随するト書きのすべて。

**朗読台本のほうは検査対象ではない。** 台本には、逐語録にない台詞を足すことがある
（観客に通じない制度名の説明など → `facilitation_guide.md` §6-4）。
これは逸脱に数えない。**定型文を守ったかどうかは、あくまで逐語録で見る。**

**判定**:

1. ファシリの発言を全部抜き出し、対応する `facilitation_guide.md` §2-1 の定型文と
   **文字列比較する**。穴（役名・{N}年・固有名）以外の差分を1件ずつ数える
2. ファシリのト書きが、§2-3 の相槌の許可リストか、定型文の中に含まれるト書き
   （A-5 の《{サブファシリ名}が、ボードの{役名}さんの欄を読み上げる》等）の
   どちらかに一致するかを見る。
   **どちらでもないト書きは違反**——とくに配役の身体・表情・動きの描写
3. リフレクティング（A-7）は、**文面は定型化していないが、形は定型**（→ A-7）。
   文字列比較の対象外だが、**次は検査する**——
   予告と閉じの定型文が一字一致か／切り出しがサブか／往復になっているか
   （独白が二つ並んでいないか）／〔A〕進行上の事実から始めているか／
   〔B〕自分の側のこととして話しているか／場の複数の声を一つの構図にまとめていないか。
   §5 と「配役の内面を断定しない」も適用する

**V6 の対象は A層（逐語録に載るファシリの発言とト書き）。B層は V7 で見る。**

### V7: B層のターン指示の逸脱

**検査対象**: `turn_log.md`（演出家が配役に送ったターン指示の全文ログ。
`facilitation_guide.md` §0-2 で記録が義務づけられている）。

**判定**:

1. 送った【場の台詞】が、対応する §2-1 の定型文と**一字一致**するか。
   **V6 は逐語録を、ここでは送信ログを見る**——
   送信時に変えて逐語録には正しく書いた場合は、ここでしか出ない
2. 枠（【ターン】【逐語録】【場の台詞】【場面】【問い】【指摘】
   【まだ想起を語っていない人】【時制】）の外に文がないこと。
   **どの欄が使えるかは、ターンの種類で決まる**（§2-2 の各枠を参照）
3. 【まだ想起を語っていない人】のリストが、その時点の実態と合っているか。
   **語り手自身の名前が残っていないか**
4. 行動表明ターンに【時制】の行があるか

**判定3だけは文字列比較ではない。** リストは毎ターン変わるので、
固定文面との突き合わせでは検査できない。「**その時点で実際に未想起の人の集合と
一致しているか**」という計算による照合が要る。手間はここだけかかるが、
**リストの脱落こそ V1 の直接原因**なので、V7 の最大の価値はこの判定にある。

**「未想起」は、想起ターン（A-2・A-3）をまだ受けていない、という意味**——
逐語録に台詞があるかどうかではない。依頼者は心配事を先に話すが、
想起を受けるまでは未想起である。心配事への言及は V1 の除外②で扱う。

## 質の評価

- **S1: 一つの変化として読めるか** — システム図に書いた膠着の構図が、
  それぞれ本人自身の「私は〜をやめて、〜した」という語りでほどけているか。
  全員分を合わせて読んだとき、組織が一つ変わった、という物語として読めるか。
  **あわせて逆向きも見る**——**読めすぎていないか**。
  特定の一発話が3人以上の転機として挙げられていたら報告する
  （実測では3人が同じ出来事を「心配をやわらげたもの」に挙げ、
  分散した変化の物語が一点の英雄的瞬間に寄りかけていた）
- **S2: 意外性** — 台本（シート・システム図）にない発明が起きたか。
  どの発明が**どの空隙**から出たかを記録する。空隙は3層にある:

  | 層 | 装置 |
  |---|---|
  | シート | 核のみ／ほぼ白紙、「まだ言葉になっていない声」を半分だけ書く |
  | 進行 | 逐語録の環流、A層の問いかけ |
  | 板書 | 「合っていますか」だけの問い |

  **対立軸は「演出 ⇄ 定型」でも「指定するか／空隙を空けるか」でもなく、
  出力の義務があるか／ないかである。**

  | 装置 | 出力の義務 | 1ターンあたりの発明収率（実測） |
  |---|---|---|
  | 板書確認「合っていますか」 | **なし**（「はい、合ってます」で終えてよい） | **50%** |
  | 想起ターン | 実質あり（語り手の持ち時間） | 42% |
  | 反応ターン（**廃止**） | **あり**（何か動いたかを毎回答える） | **8%** |

  板書確認は**何も言わずに済ませられる装置なのに、8/8 で言い直しが出た**。
  反応ターンは同じく機械的だが、毎回答える義務があり、収率は 8% に落ちた。
  **機械性ではなく、義務の不在が効いている。**

  **1つの発明が複数の空隙の積になることがある**（シートの空隙＋板書の空隙）。
  単一の層に帰属させず、**併記して数える**。数を層ごとに比較したいなら、
  併記分をどう扱うかを集計前に決めておく
- **S3: 型の反復** — V1〜V7 は「1発話の中の瑕疵」を単位にしているが、
  失敗の一部は**コーパス全体に分布する型の反復**として現れる。
  逐語録全体を grep し、**同一の型が7人中4人以上に現れたら報告する**。
  あわせて、**板書確認の言い直し率が 1/7 を大きく超えたら報告する**——
  言い直しの**方向**も見る（実測では8件中6件が「自分を良く見せている語を、
  自分を弱く見せる語に置き換える」型で、格上げ方向が0件だった）。
  **これは違反ではない。** 報告して、設計側が判断する材料にする。
  ただし「7人が同じことを言った」は、**7人がそう思ったのか、
  7人が同じ逐語録を読んで真似たのか**を区別しない。区別できないことも含めて報告する

**S1・S2・S3 にも、V項目と同じ出力義務を課す。**
「留保 N件。各件に行番号・引用・修復案、**または明示的な不採用理由**」。
散文で所見を添えるだけにしない。採らないなら、採らない理由を書く。

## 局所修復の原則（テストで不自然な表現が見つかった場合）

- 局所修復のみ。事実と声を保存し、その箇所だけ書き換える
- 他人の台詞の引用は、**その人の別の日常的な行動の描写に置き換える**
  （言い淀みや「お任せします」でごまかすと、作者の都合の
  物分かりの良さになり不自然）
- 対になっている箇所（AがBの行動に触れている）は両方を対で直す
- 迷ったら、そのブロックだけ配役に生成し直させる方が声が保たれる

### この原則は、事後修復だけでなく進行中の即時修復にも効く

実測では、V1違反3件を「他人の台詞の引用 → その人の行動描写に置換」で修復し、
**3件とも修復後のほうが元より良くなった**。

例: 「浜岡さんが〜と言った」（未想起者の台詞の創作）を、
「浜岡が資料の数字欄を赤枠で囲っていた／該当ページだけ印刷の色が違った」に置換。
台詞引用版より具体的で、S2 の発明にも数えられた。

つまり、進行中に V1/V4 を見つけてその場で言い直させることは、**傷の応急処置ではなく、
語りを強くする機会**でもある。ためらわずに止めてよい。

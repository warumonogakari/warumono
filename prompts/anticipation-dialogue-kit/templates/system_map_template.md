# システム図テンプレート（演出家専用・配役には渡さない）

ケースを作るとき、このファイルを埋める。**配役エージェントには絶対に見せない**——
これは「組織がなぜ膠着しているか」の全体図であり、配役が知ってしまうと
情報隠蔽が壊れ、物分かりの良い予定調和が始まる。

## 膠着の構図（組織システム）

役割ごとに「維持行動」を一行で書く。各自が善意で続けている行動が、
合成されると膠着になっている——という構図にする。

- **{役割A・膠着の中心}: {構図名}** — {何がこの人に集まり、何が言えなくなっているか}
- **{役割B}: {構図名}** — {善意の行動が、どう圧/壁/距離に変換されているか}
- **{役割C…}**: …
- **{依頼者}: {構図名}** — {一人で異変に気づき、この場を持ち込んだ経緯}

書き方の要点:
- 各構図は**その人の視点では合理的**であること（悪役を作らない）
- 構図同士が噛み合って膠着していること（一人を直せば解決、にしない）

## 変化のベクトル（内容は指定しない）

各自が「自分の維持行動」を{N}年後から過去形で手放して語る。
{人数}の一人称が、合成すると一つの組織システムの変化として読めること。
**何をどう手放すかは配役の発明に委ねる。ここには方向だけ書く。**

例: 抱え込みの分散・圧の変換・防衛の開放・分業の越境・声の環流・心配の共有化

### 手放し方は一種類ではない

全員が「〜をやめました」に着地すると、語りの内容は割れていても**形が揃ってしまう**。
構図ごとに、どの型で解けるかを設計してよい。実測で出た4型:

| 型 | 中身 | 例 |
|---|---|---|
| **やめる** | 維持行動そのものを捨てる | 「すべての調整会議に出るのを、やめました」 |
| **やめない** | 続けると決め直す。二重否定は、迷った末の継続を表せる | 「正直に書くのを、やめなかったことです」 |
| **意味の差し替え** | 同じ行為を続けたまま、問い方・目的を変える | 「聞き方を変えます。『遅れてないか』じゃなくて、『どこで詰まってるか』を」 |
| **宛先・機構の変更** | 自分が判断していたことを、場に置いて誰かが気づく形に移す | 「伝えるタイミングを私が選ぶんじゃなくて、書いておいて、気づいた人が勝手に気づく形に変えた」 |

**この4型を配役に指示しない。** ここに書くのは設計側の見取り図で、
どの型で解くかは配役が発明する。ただし**システム図が「手放し」一語で構図を組むと、
配役の側には「やめる」以外の選択肢が見えにくくなる**（実測: 演出家が
「手放し」の文言を一度も反復しなくても、大枠は「やめる」型に着地した）。
構図を書くときに、型の偏りを意識しておく。

## 台本化しない要素

ここに「決めたくなるが決めてはいけないこと」を明示的に列挙する:

- {ケースの核心となる出来事}を誰がいつどう明かすか、相手がどう反応するか
- 涙・和解の形・堰が切れるかどうか
- 発言順の揺れ・沈黙の長さ・誰の感情が最初に動くか

## 内面シートの書き込み量

全員を濃いシートにしない。3段階を混ぜると、自己発明の余地が声の多様性になる:

- **フル**: 主人公・依頼者など、構図の中心（実感・秘密・話し方まで書く）
- **核のみ**: 「あなたの実感（核）」1〜4行＋「それ以外は白紙です。発明してください」
- **ほぼ白紙**: 役割と立場のみ。人物像ごと自己発明

## 進行順（ケースごとに決める）

依頼者の心配事 → 時間設定({主人公}) → ジャンプ → {主人公} → {メンバー…}
→ {支援者…}(支援者2ターン) → リフレクティング → {依頼者}(支援者2ターン)
→ {依頼者}への最後の質問 → 帰還 → 行動表明(全員・{主人公}が最後)

**演出家はここに書いた順を実行するだけ**で、場の流れを見て順番を変えない。
各語りブロックの内訳は固定（`facilitation_guide.md` §1）:

- チーム内メンバー: 想起3ターン → 板書確認
- 支援者: 想起2ターン → 板書確認
